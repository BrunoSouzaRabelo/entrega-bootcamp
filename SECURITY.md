# Política de Segurança do PortfolioHUB

O PortfolioHUB leva a segurança a sério. Abaixo estão as diretrizes para relatar vulnerabilidades e o escopo de suporte deste repositório.

## Versões Suportadas

Atualmente, apenas a versão principal de produção recebe atualizações e patches de segurança.

| Versão | Suportada          |
| -------| ------------------ |
| v1.0   | :white_check_mark: |
| < v1.0 | :x:                |

## Reporte de Vulnerabilidades

Se você descobrir alguma vulnerabilidade de segurança (como exposição indevida de dados pessoais ou falhas no código), **NÃO abra uma Issue pública**.

Por favor, reporte o problema de forma confidencial diretamente para o administrador do repositório através do e-mail:
📧 **bruno.rabelo@sempreceub.com**

Todos os relatórios de segurança são lidos e tratados em até 48 horas úteis. Assim que o problema for resolvido, atualizaremos o repositório e informaremos o responsável pelo reporte.
